DATABASE SCHEMA (Supabase / PostgreSQL)
================================================================================

TABLE: tasks
------------
id           uuid        PRIMARY KEY (auto-generated)
user_id      uuid        REFERENCES auth.users(id) ON DELETE CASCADE
title        text        NOT NULL
done         boolean     DEFAULT false
category     text        DEFAULT 'Work'   -- Work | Personal | Travel | Urgent
priority     text        DEFAULT 'Medium' -- Low | Medium | High
start_date   date        NULLABLE
due_date     date        NULLABLE
completed_at timestamptz NULLABLE
created_at   timestamptz DEFAULT now()

RLS: Users can only access their own rows (auth.uid() = user_id)

TABLE: profiles
---------------
id           uuid        PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE
username     text        NULLABLE
email        text        NULLABLE
phone        text        NULLABLE
location     text        NULLABLE
avatar_url   text        NULLABLE
bio          text        NULLABLE
role         text        DEFAULT 'user'  -- user | admin
updated_at   timestamptz DEFAULT now()

RLS: Users can only access their own row (auth.uid() = id)
Trigger: handle_new_user() auto-creates profile row on signup

TABLE: announcements
--------------------
id           uuid        PRIMARY KEY (auto-generated)
title        text        NOT NULL
body         text        NOT NULL
type         text        -- info | warning | success | alert
target       text        -- all | admins
created_at   timestamptz DEFAULT now()

RLS: Public read, authenticated write

TABLE: app_settings
-------------------
key          text        PRIMARY KEY
value        text        NOT NULL
updated_at   timestamptz DEFAULT now()

Default rows:
  maintenance_mode     = 'false'
  email_notifications  = 'true'
  push_notifications   = 'false'
  max_tasks_per_user   = '100'
  allow_signups        = 'true'
  force_signout        = 'false'

RLS: Public read, authenticated write

STORAGE BUCKET: avatars
-----------------------
- Public bucket
- Path: {userId}/avatar.{ext}
- Policies: authenticated users can upload/update their own folder

SQL FUNCTIONS
-------------
delete_user()
  - Security definer function
  - Deletes auth.users row for the calling user (auth.uid())
  - Called via supabase.rpc('delete_user')

handle_new_user()
  - Trigger function on auth.users INSERT
  - Auto-creates profiles row with username from metadata
  - Has exception handling to not block signup on failure

SERVICES & KEY FUNCTIONS
================================================================================

tasksService (src/services/tasksService.ts)
-------------------------------------------
fetchTasks(userId)          → SELECT all tasks for user, ordered by created_at DESC
createTask(userId, task)    → INSERT new task row
toggleTask(id, done)        → UPDATE done + completed_at
deleteTask(id)              → DELETE task by id
updateTask(id, updates)     → UPDATE title/category/priority/dates
clearAllTasks(userId)       → DELETE all tasks for user

profileService (src/services/profileService.ts)
------------------------------------------------
getProfile(userId)          → SELECT profile row
upsertProfile(userId, data) → INSERT or UPDATE profile (onConflict: id)
uploadAvatar(userId, file)  → Upload to Supabase Storage avatars bucket
deleteAvatar(userId, url)   → Remove from storage + clear avatar_url in DB

notificationService (src/services/notificationService.ts)
----------------------------------------------------------
loadNotifPrefs()            → Read notification prefs from localStorage
saveNotifPrefs(prefs)       → Write notification prefs to localStorage
sendTaskReminderEmail()     → Filter tasks due today/tomorrow → send via EmailJS
sendVacationAlertEmail()    → Send trip summary via EmailJS
sendEmailDigest()           → Send pending tasks + trips digest via EmailJS
sendAnnouncementEmails()    → Broadcast announcement to list of users via EmailJS

useGooglePlaces (src/hooks/useGooglePlaces.ts)
----------------------------------------------
search(query)               → Google Places Autocomplete suggestions
fetchNearby(placeId)        → Get nearby attractions, hotels, restaurants
clear()                     → Clear autocomplete suggestions
clearNearby()               → Clear nearby results

================================================================================
PASSWORD RESET FLOW
================================================================================

1. User visits /forgot-password
2. Enters email → supabase.auth.resetPasswordForEmail() called
   - redirectTo: {origin}/reset-password
3. Supabase sends email with magic link
4. User clicks link → lands on /reset-password
5. supabase.auth.getSession() verifies the token
6. User enters new password → supabase.auth.updateUser({ password })
7. Redirected to /login after 3 seconds

Supabase config required:
- Site URL: http://localhost:8080
- Redirect URL: http://localhost:8080/reset-password

================================================================================
ACCOUNT DELETION FLOW
================================================================================

1. User clicks "Delete Account" in Settings
2. Confirmation dialog appears
3. User must type "DELETE" exactly to enable the confirm button
4. On confirm:
   a. supabase.rpc('delete_user') → deletes from auth.users (cascades to tasks, profiles)
   b. supabase.auth.signOut()
   c. localStorage.clear() + sessionStorage.clear()
   d. Redirect to /signup

SQL function required:
  create or replace function delete_user()
  returns void language sql security definer as $$
    delete from auth.users where id = auth.uid();
  $$;
